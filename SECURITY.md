# Security Policy

## Supported versions

Only the latest release receives security fixes. If you run an older version, upgrade to the
latest release before reporting an issue, and confirm it still reproduces.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Email the maintainers at sean.whitney@broadcom.com with the subject line "appneta-ia-bridge security".
Only the maintainers see the report.

Include as much of the following as you can:

- The release version, or the commit, you tested.
- A description of the problem and its impact.
- Steps to reproduce, or a minimal example request or payload.
- Relevant logs, with secrets, API keys, and certificates removed.

## What to expect

Reports are reviewed by the maintainers, who will acknowledge receipt, ask for more detail if
needed, and keep you informed as the issue is assessed. Confirmed vulnerabilities are fixed in a
new release and described in [`CHANGELOG.md`](CHANGELOG.md). Please keep the details private until
a fixed release is available.
